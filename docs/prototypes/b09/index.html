B09 GUI 风格原型

三套原型的信息结构相同，都是「日常收取」模块页（窗口按 1280×800 设计），只有视觉风格不同。数据照 B08 接口的真实形状模拟。可以点「开始演练」看日志滚动和急停，也可以关掉演练开关看实跑时的警示样式。

D 游戏风（已选定）配色和部件取自游戏截图：深藏青半透明圆角面板、带菱形装饰的米金色分隔线、左侧菜单选中时的蓝色辉光（仿竞技场菜单）、精灵之森式的胶囊计时、邮件列表式的设置行、准备战斗式的底部行动条（绿色主按钮、古铜次按钮）、橙红角标。背景是圣域（进入圣域时 UI 淡入前的一帧，bg_sanctuary.jpg），用 CSS 压暗。实跑时提示条和主按钮变红。只用系统字体。 A 工作台浅灰底、深色顶栏，信息密度高，像仪器面板。倒计时用系统自带的 Bahnschrift 窄体数字。实跑时横条变成红色斜纹。三栏布局，画面和日志常驻右侧。 B 星辰书卷贴近游戏本身的深靛蓝加金色，标题用宋体（衬线），面板有描金边角。实跑时印章变红、按钮变红。需要随应用打包衬线字体（中文字体子集化后约 1–3 MB）。 C Windows 原生仿 Windows 11 设置应用：Segoe 字体、Fluent 图标、设置卡片式表单，跟随系统深浅色（右上角可以切换）。JSON Schema 表单最容易做成这种逐行卡片的样子。
