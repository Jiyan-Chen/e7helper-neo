# B12c 审核记录：书签刷取：历史统计

状态：✅ 已通过 · 日期：2026-10-20（同日审核通过）

## 起因
B12b 审核后用户提出：「优化一下刷书签页面，加个可以统计历史情况的 feature，把 app 原有的统计页面删掉」。补充：统计只做书签刷取，日常收取、重复刷关的不要；不单独做页面，放进书签刷取的页面；表现形式由我定（审核时再调）。不操作真机。

## 设计（我的决定，请审核时看）
- **位置**：书签刷取页「设置」下面一块「刷取历史」面板，**代替**原来通用的「最近运行」（刷取历史的每次运行明细比它详细，两个都放会重复）。别的功能页仍是「最近运行」。
- **时间范围**：面板右上 近 7 天 / 近 30 天 / 全部（默认近 30 天，记住上次选的）。下面所有数字、图表、列表都按这个范围。
- **看什么**（从上到下）：
  1. 商品卡：誓约书签 / 神秘奖牌 / 友情点数（设置里选了的、或以前买到过的才显示）。每张：出了几次、共几个（书签 ×5、奖牌 ×50；友情点数不写个数）、「平均刷 N 次出一次」（= 看过的页数 ÷ 次数；进店时那一页也算一页）。没出过写「还没出过」。
  2. 四个数字：刷新次数、花费天空石、花费金币（按「万」）、运行次数（换过频道时后面小字「换频道 N 次」）。
  3. 柱状图「每天刷新次数」：没跑的天是空柱；柱子上方用小图标标出那天买到的书签 / 奖牌；悬停看那天刷新 / 天空石 / 金币 / 买到什么。「全部」跨度超过 45 天时改成「每周刷新次数」（周一开始）。
  4. 每次运行：时间、刷新几次、天空石、金币、换频道，右边是买到的商品图标（同一种多个时写 ×N，悬停看是进店时还是第几次刷新出的），下一行灰字是结束原因（「达到最多刷新次数 10」「手动停止」等）。默认 6 条，「显示全部 N 次」展开。
  5. 没有记录时只写「还没有刷取记录。」；选的范围里没跑过写「这段时间没有刷取。」
- **只算实跑**：dry-run 的记录在引擎里就去掉了（开发版、正式版都一样）。
- **数据来源**：全部从 `history.jsonl` 算（含按天汇总），不读 `stats.json`。两者是同一次写入的，`history.jsonl` 有时间和明细，能按天分；`stats.json` 照常写，留给以后用。
- 说明文字按「只讲功能」的偏好：面板里没有说明句，只有标题和数字。

## 交付内容
### 引擎
- `secret_shop/stats.py`：
  - `load_history(data_dir)`：读全部记录，坏行跳过；
  - `report(records, runs_limit=500)`：去掉 dry-run，按开始时间的本地日期汇总（运行次数、刷新、天空石、金币、页数、买到的商品、换频道），每次运行的明细新的在前；B04 时期没有 `max_misses` / `channel_switches` 的旧记录按 0 算；结束原因里的 `TaskStopped：…` / `TaskTimeout：…` / `TaskStuck：…` 换成「手动停止 / 超过时限 / 画面卡住」，其他异常写成「出错：消息」。
- `secret_shop/__init__.py`：`routes()` 新增 `GET /api/modules/secret_shop/report?runs=500`（要 token）。`GET /api/modules/{id}/stats` 保留不动。

### GUI
- 删除：`src/pages/StatsPage.tsx`、`App.tsx` 的 `stats` 路由（旧地址 `#/stats` 会回到首页）、左侧菜单的「统计」、`ModuleUI.statLabels` 和四个模块里的 `statLabels`、`api.stats` / `ModuleStats`（没人用了）。
- 新增：
  - `ModuleUI.RunsPanel`：代替通用「最近运行」的面板；`ModulePage` 有它就画它。
  - `api.moduleGet(id, path)`：调模块子路由。
  - `src/modules/secret_shop/report.ts`：数据形状和汇总（范围、按天 / 按周的柱子、平均几次出一次、金币按万）。
  - `src/modules/secret_shop/ShopHistory.tsx`：「刷取历史」面板。查询键挂在 `qk.stats("secret_shop")` 下，任务结束的 `stats` 事件会让它刷新。
  - `src/modules/secret_shop/items.ts`：三种商品（名字、图标、一次几个），`ItemPicker` 和历史面板共用。

## 已知问题
- 「平均刷 N 次出一次」按看过的页数算（每次运行进店那一页也算），和「刷新次数」差每次运行 1 页；记录多了以后差别很小。
- 书签 ×5、奖牌 ×50 是按游戏里秘密商店的固定数量写在前端的（`items.ts`），游戏改了数量要跟着改。
- 天按开始时间的本地日期算：跨零点的一次运行全部算在开始那天。
- 「最近运行」原本能看到失败 / 急停的任务和来源（手动 / 计划）；书签刷取页换成刷取历史后，这些在「运行记录」页里看（失败原因在刷取历史的结束原因里也有）。
- 开发版里演练的记录也不显示（按「dry-run 不算」）。要看演练跑得怎样看「动态」或「运行记录」。
