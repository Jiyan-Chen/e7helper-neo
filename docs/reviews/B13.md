## 第一轮审核意见和修改（2026-10-21）
用户意见：「右下角属性的显示使用游戏内的图标，你可以从游戏里获取资产，然后除了角色的面板属性，最好还要加上技能，fribbels 上的配装方案，参照 https://e7.wiki/characters 上的角色详情面板」。中途补充：「不需要做立绘页面」。

### 调研
- **e7.wiki** 是面向国服的中文站（有国服中文配音信息），389 名英雄，名字和 Fribbels 简中完全一致，只多了「梅铃」（Fribbels 缺的那一名）。公开数据：
  - `admin.e7.wiki/api/open/epicseven/hero/card-list`：全部英雄的中文名、**昵称（含拼音）**、更新时间；
  - `assets2.e7.wiki/static/heroes/<slug>.json`（每名约 7KB）：技能名、带高亮词的描述、效果（带图标）、强化、冷却、灵魂燃烧、倍率、专属装备，角色奉献，简介；slug 就是 Fribbels 的 `_id`（389 名全部一致）。
  - 详情面板是 角色信息 / 技能详情 / 配装方案 / 立绘 四个页签；它的「配装方案」是从 Fribbels 配装库整理来的。
- **Fribbels 配装库**（fribbels.github.io/e7/hero-library）用的接口 `krivpfvxi0.execute-api.us-west-2.amazonaws.com/dev/getBuilds`：POST 英雄英文名，返回玩家上传的全部配装（苏莉塔妮亚 2874 份、680KB、约 4 秒）。
- 神器中文名：Fribbels `artifactdata.json` + 简中翻译，288 / 288 都有；神器图标在官方指南站 `.../wearingStatus/images/artifact/<编号>_ico.png`。

### 修改
- **英雄详情（e7.wiki）**：`core/data/hero_detail.py` 把 e7.wiki 的数据转成我们的格式（富文本：段落 → 片段，`hl` 是游戏里高亮的词），每名一个 `details/<编号>.json`，技能 / 效果 / 专属装备图标放 `details/icons/`。随包 389 份 + 1394 个图标，共 8.3MB。怪物英雄 m0063 / m0171 e7.wiki 没有，没有详情。
- **名字和昵称**：中文名优先用 e7.wiki 的（梅铃有了中文名），其次 Fribbels 简中；e7.wiki 的昵称写进 `aliases`（和名字一样的去掉），搜「星法」「xingfa」「梅林」都能找到；详情里只显示带汉字的昵称。
- **联网更新**：在 Fribbels 之后拉 e7.wiki 角色列表；每名英雄的详情只在 e7.wiki 的更新时间变了时重新下载（8 线程），缺的图标才下。e7.wiki 连不上时只更新 Fribbels 那部分，沿用现有的中文名和昵称，结果里带 `wiki_error`。神器表 `artifacts.json` 也随更新写。
- **配装方案**：`core/data/hero_builds.py` 取 Fribbels 配装库原始数据，按 Fribbels 网页的规则把套装件数换算成完整套装，汇总成前 8 个套装组合（占比、份数、平均属性、组合里常用的 3 件神器）、全部配装的前 8 件神器、整体平均属性；缓存一天（`<数据目录>/data/heroes/builds/`），可以手动刷新，下载失败但有旧缓存时显示旧的。
- **游戏图标**：从两张游戏截图裁出 5 个属性、6 个职业、24 个套装图标，按和按钮底色的差距抠成透明 PNG，放 `app/src/assets/game/`（35 个，156KB）。`lib/gameIcons.ts` 按文件名自动收集，用在图鉴头像右下角、筛选按钮、详情的属性 / 职业标签、配装方案的套装。
- **叫法对照游戏改了**：属性面板「效果抗性」「夹攻率」「攻击力 / 防御力 / 生命值」（原来写的效果抵抗 / 夹攻 / 攻击…）；套装 24 个名字按背包的套装筛选核对：生命值、破灭、憎恨（Revenge）、守护（Protection）、逆袭（Reversal）、回击（Riposte）等。
- **详情弹窗**（`components/heroes/HeroDetailDialog.tsx`，参照 e7.wiki，760px 宽）：
  - 角色信息：头像、英文名、星级、属性 / 职业（游戏图标）/ 星座、昵称、简介；角色奉献（自阵 / 群阵，SSS 值 + B～SSS 每级）；专属装备（主属性范围、说明）；满级属性。
  - 技能详情：每个技能一张卡：图标、名字、技能序号 / 灵魂 +N / 冷却，描述（高亮词橙色），灵魂燃烧，专属装备效果（多选一），技能特效（带图标，强化蓝 / 弱化红），技能强化 +1～+N，倍率。
  - 配装方案：份数和最新日期、刷新；平均属性；套装组合（套装图标 + 名字 × 件数、占比条、平均属性、常用神器带图标和占比）；常用神器。
- 新接口：`GET /api/heroes/{code}/detail`、`GET /api/heroes/{code}/builds?refresh=`、`GET /api/hero-icons/{name}`（技能等图标，文件名做了路径检查）、`GET /api/artifacts/{code}/icon`（第一次用时从官方指南站下载并缓存）。`GET /api/heroes` 的 `labels` 加了套装、属性类型和哪些是百分比。

## 设计（第一次提交）
- **位置**：`engine/e7helper/core/data/`（分层图里预留的 `core/data`），只依赖 `core.paths` / `core.imageio` / `core.vision.ocr.normalize_text`，不依赖设备；助手模块（只读帧）直接 `from e7helper.core.data import heroes` 就能用。
- **两份数据取较新的**：`heroes.json` 带 `updated`（内容最后一次变化的时间，UTC）。读随包和数据目录两份，用较新的；所以装了新版本（随包数据更新）后，旧的联网数据自动让位。
- **更新只在有变化时写**：拉下来转换后和现在用的那份逐名比对（新增 / 删除 / 变化），没变化不写文件、不改 `updated`。新数据比现有少一成以上（来源出问题）就拒绝覆盖。头像只下载随包和数据目录都没有的。
- **国内网络**：依次试 raw.githubusercontent.com 和 jsDelivr 镜像，记住能用的那个。头像连续失败 5 次就不再试（网络断了不用每个都等超时），剩下的下次更新再补。
- **名字查找**：`find` 精确匹配中文名 / 英文名 / 别名，比对前忽略空白、全半角、大小写和「·」，以后 OCR 读到的名字可以直接查；`search` 按「完全一致 → 开头一致 → 包含」排序。前端 `filterHeroes` 用同一套规则。
- **修正表**：`assets/data/heroes/overrides.json`（按编号改中文名、加别名），加载时套用，联网更新不会冲掉。现在是空的（只有说明）。
- **写盘格式**：`heroes.json` 一名英雄一行，以后更新时 git diff 好看。
- 模块 `heroes.py` 改名为 `hero_db.py`：包里导出的函数 `heroes()` 会盖住同名子模块（`from e7helper.core.data import heroes` 拿到的是函数）。

## 已知问题
1. **国服名不一定全对**：中文名用 e7.wiki 的（面向国服，和 Fribbels 简中一致），没有逐个和游戏核对；e7.wiki 和 Fribbels 都没有中文名的新英雄先显示英文名（现在只有 aespa 联动的 4 名，游戏里本来就是英文）。对不上的写进 `overrides.json`。
2. **国服和外服的英雄可能不同步**：数据是外服的全部英雄，国服还没出的英雄也会列出来。
3. **版权 / 依赖第三方**：Fribbels 仓库没有许可证；头像、技能图标是 Smilegate 的游戏素材；e7.wiki 的数据和 Fribbels 配装库接口都不是公开 API，人家一改就会坏（随包数据不受影响，配装方案会显示「取不到」）。自用没问题，公开分发安装包前要再考虑。
4. **联网依赖**：更新依赖 GitHub / jsDelivr 和 e7.wiki；配装依赖 Fribbels 的 AWS 接口（国内大约 4 秒）；神器图标第一次显示时从官方指南站下载。都没有代理设置。
5. 头像是 Fribbels 缓存的 112×112 小图；以后做识别时，游戏里的头像和这里的构图、边框可能不一样，到时再看真实画面。
6. 游戏图标是从截图裁的，按底色差距抠的透明：暗属性月亮的黑色描边、职业图标里的黑色部分变成了透明（在深色界面上看不出来）。分辨率是游戏 1600×900 下的原大（约 30–40px），放大显示会糊。
7. 配装汇总只取前 8 个套装组合，没有 Fribbels 网页上按装备分数 / 神器筛选的功能。
8. 英雄数量多了以后，图鉴页一次渲染全部卡片（现在 389 张，没感觉卡），没做虚拟列表。
9. 随包数据从 4.6MB 涨到约 13MB（详情和技能图标 8.3MB）。
