# B06 审核记录：重复刷关（托管战斗 + 手动刷关）

状态：✅ 已通过 · 日期：2026-10-16

## 范围（开工时和用户确认）
- 国服把以前的「重复战斗」重做成了 **托管战斗**：在准备界面设份数（1 份 = 4 次），用行动力或生命之叶付费，宠物在后台按最快通关记录自动打（游戏离线也照常进行），打完在托管框里「结算」领奖。**没有通关记录（「无记录」）的关卡开不了托管。**
- 用户要的两个功能：
  1. 托管：自动结算已完成的托管，并在同一关重开；
  2. 托管在后台跑的同时，手动反复点「战斗开始」刷某一关。
- 先支持 **从大厅自动导航到讨伐**（选地下城 + 难度）；另有 `start_here`：从当前准备界面开始（以后接 Episode、支线等可重复刷的关卡）。
- 不用「快速战斗」（扫荡）；**迷宫不做**。
- **异界难度不做**：异界消耗的是异界专用代币（不是行动力）。阿吉玛纳克 / 卡戴斯 / 食人魔只有异界难度，所以先只支持 双足飞龙 / 魔像 / 报丧妖 的 中级 / 上级 / 地狱级（用户在开发途中确认）。
- 行动力不够：默认停止；可配置用生命之叶 / 天空石补充，各自设次数上限（叶子优先）。背包已满：停止。
- 开托管时勾选「优先使用持有的行动力」（用户要求）。

### 流程
1. **导航**：大厅 →「战斗」→「讨伐」卡片 → 右侧列表 OCR 找「讨伐<地下城>」（找不到就往下翻两次，再翻回顶部）→ 中间难度卡片 OCR 找「讨伐<难度>」（**难度卡片随地下城变化**，后出的地下城只有异界）→ 准备界面，OCR 核对右上的关卡名和难度，不对就返回重选一次。
2. **托管**（准备界面）：顶栏托管图标 → 没有 / 进行中 / 完成。
   - 完成：点「托管战斗」→ 进度框「结算」→「结算完毕」点击关闭 →「关闭」→ 核对顶栏图标消失。
   - 没有托管：先切到普通战斗模式（**「无记录」只在普通战斗模式显示**），无记录就跳过；否则打开设置框，按 `plan_auto` 算份数：勾选优先行动力时先用行动力凑整份（每份 = 单次消耗 × 4），再加最多 `auto_leaves` 片叶子；把份数调到目标（「最少」→ 逐次 +1，每次看读数变化），**核对「将使用」的行动力和叶子**后点开始 → 确认框「是否开始托管战斗？」点确认 → 核对顶栏出现进行中图标、行动力减少量等于将使用的行动力、天空石不变。
3. **手动刷关**：每回到准备界面先看托管是否完成（完成就结算并重开）→ 切到普通战斗（游戏每次回准备界面默认是快速战斗）→ 读按钮上的「消耗/持有」→ 战斗开始 → 战斗中检查自动战斗（图标在转 = 开着）→ CLEAR（点一下）→ 结算「确认」→ 战后读「持有」→ 核对 → 「重新进行」回到准备界面。
4. **行动力不够**：没开补充 → 停止；开了 → 点战斗开始弹出「行动力不足」框（按钮读数和顶栏读数都不够时才点）→ 选中要用的选项（左叶子 / 右天空石），核对选中项（亮边框）、价格（1→80 / 30→60）、持有量和保底 → 购买 → 核对行动力增加 80 / 60（允许自然回复 +2）、天空石读数（叶子：不变；天空石：-30）。

### 安全规则
- 手动一场 = 看到 CLEAR + 战后「持有」比开打前减少 **不超过** 一场消耗（讨伐会掉落行动力，实测掉 11 / 13，减少量可能更小）。多扣立即停止，任务记为失败。
- 托管：「将使用」与计算不符、份数没调到、勾选状态不对 → 不点开始。开始后读数不符 → 失败。
- **进行中的托管框只点底部空白处关闭，绝不点「中断」**（`read_auto_progress` 在进行中不返回按钮；模拟器点到中断进入 DANGER）。
- 点了确认 / 购买 / 关闭之后，**等框自己淡出**，不交给弹窗规则（否则淡出时会再点一次取消或底部，见下文实测）。
- 弹窗规则：托管确认框、行动力不足框自动关闭时点取消；托管进度框 / 设置框点底部空白（`(800, 878)`，框关闭后这里在准备界面也是空白）。
- 点战斗开始后出现认不出、**静止**的弹窗（例如背包已满）超过 4 秒：停止并记为失败（保存调试截图），不乱点。
- dry-run：不点「结算」「开始」「战斗开始」「购买」；会打开托管设置框调份数和勾选框读数（不消耗），然后关闭。

## 已知问题 / 后续
- **只开托管时不会持续守着**（用户确认的设计）：`auto_battle` 开、`manual` 关时，模块结算 / 重开一次就退出，之后托管再完成要等下次运行。周期性的「托管完成就结算重开」由 B08 / B09 的定时调度反复启动本模块实现，不在模块里挂着等（挂着会一直占用任务互斥，期间跑不了别的模块）。同时开手动时，每打完一场都会检查托管。
- **背包已满没见过**：用户背包没满，没有截图。点开始后出现认不出的静止弹窗会停止并记为失败（有调试截图），以后据此补模板。
- **补行动力没有实跑**（只离线测试）：买完后游戏是回到准备界面还是直接开打没见过；直接开打时模块会停止（记为失败）。天空石选项被选中时的样子也没采到。
- 「手动刷关途中托管完成 → 结算并重开」在实机上是分两次运行验证的（同一段代码，第二次运行开头走的就是变灰图标的结算）；托管用叶子重开没有实跑。
- 托管用掉的叶子只按设置框「将使用」记账：顶栏不显示叶子，开始后没法按读数差核对。
- 异界难度、后三个地下城、Episode / 支线关卡：以后另做（`start_here` 可以从任意准备界面开始，但没有在讨伐以外的关卡实测过）。
- 选中的地下城在列表里有金色边框；没有直接核对选中状态，靠进入准备界面后核对关卡名兜底（不对就返回重选一次）。
- fixtures 新增 43MB（总计约 86MB）。本模块测试约 3.5 分钟，主要花在真实截图上的模板匹配。
