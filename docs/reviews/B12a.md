# B12a 审核记录：讨伐异界

状态：✅ 已通过 · 日期：2026-10-19（2026-10-20 审核通过）

## 起因
B12 试用时用户提出：重复刷关「讨伐还有下面三个没做，然后异界难度也没做」。单独立项、单独审核（同 B10a）。

B06 时：`repeat_battle` 只支持 双足飞龙 / 魔像 / 报丧妖 × 中级 / 上级 / 地狱级；`start_here` 停在异界准备界面时直接停止（「消耗异界代币，暂不支持」）。

## 范围（开工时和用户确认）
- **补充**：加选项，允许用生命之叶或天空石补充异界代币（用户选择）。实现上没有另加开关，而是把原来的「用生命之叶补行动力 / 用天空石补行动力」改成通用的「用生命之叶补充 / 用天空石补充」：刷普通难度时补行动力，刷异界时补光谱核心，次数上限共用（我的决定，审核时可以改）。
- **托管 / 手动**：异界能托管，用代币付费；手动流程和普通难度一样（用户确认）。实跑时发现异界胜利后的画面不一样，见「实跑」。
- **表单**：讨伐目标加三个地下城、难度加「异界」；选了只有异界的地下城时**难度自动锁定成异界**（用户选择）。用户补充：**只有食人魔没有其他难度**，阿吉玛纳克和卡戴斯也有 中级 / 上级 / 地狱级。
- **托管份数**：异界开托管默认会把持有的代币全部用掉（和普通难度用光行动力的规则一样）。用户选择**把「托管最多几份」放进表单**（原来是内部字段 `auto_max_units`）。
- 真机：用户同意先导航截图（只做不消耗的操作），之后同意实跑一小轮（约 3 个代币，后来又同意加打 1 场验证修复）。

## 真机看到的规则（2026-10-19，MuMu 1600×900）
- 异界代币叫**光谱核心**，是顶栏行动力左边的红色图标，只在讨伐列表和准备界面显示，大厅和战斗菜单没有。当时持有 27 个。
- 点顶栏的核心图标（或它左上的「+」）会打开**「购买光谱核心」框**：左边是生命之叶 2 片换 1 个，右边是天空石 80 换 1 个；默认选中叶子；有数量「1/3」（最少 / -1 / +1 / 最多），底部写「此商品与商店中出售的商品相同」；按钮是「取消 / 购买」。
- 讨伐列表：阿吉玛纳克、卡戴斯有四个难度，食人魔只有「讨伐异界」。阿吉玛纳克的异界是「可进行」，卡戴斯和食人魔是「完成」。
- 异界准备界面：**没有快速战斗**，也没有右下角的切换钮（那个位置是「战斗开始」按钮的右端）；按钮上是核心「1/27」（消耗 / 持有）；有「攻掠首领」按钮；提示「辅助英雄无法参与」。
- 「无记录」：阿吉玛纳克、卡戴斯的异界都是无记录（卡戴斯虽然已完成也没有记录），点托管只弹出提示「为预估战斗时长，需先留下1次通关记录。」。食人魔有记录（00:49）。
- 异界托管设置框：「1 次消耗货币」是核心 1 或叶子 2；勾选框是「优先使用持有的光谱核心」；份数框按叶子数显示，最少 2，**每点一次 +1 加 2（= 多打 1 次）**。普通难度是 1 次 20 行动力或 0.25 叶子，份数框 1 = 4 次。
- 异界战斗胜利后**没有 CLEAR 和「确认」结算页**：出现宝珠画面「请轻触屏幕领取奖励。」，点一下直接到战后界面「完成奖励」（离开 / 大厅 / 奖励信息 / 核心「1/25」重新进行）。
- 异界托管进度框、结算流程和普通难度相同（「讨伐异界 1/1」→ 结算 → 结算完毕 → 关闭）。

## 安全规则
- 异界一场 = 看到宝珠画面（或 CLEAR / 结算）+ 战后「持有」核心比开打前减少**不超过**一场的消耗（1 个）。多扣立即停止，任务记为失败。
- 托管：设置框「1 次消耗」的叶子读数必须是预期值（普通 0.25、异界 2，异界读不到也不开），份数、将使用的核心 / 叶子、勾选状态都对上才点开始；开始后顶栏核心减少量必须**正好**等于将使用的核心（核心不会自然回复，不留余量）、天空石不变。
- 补核心：核心不够一场时才补；**不点「战斗开始」去触发**，点顶栏核心图标打开购买框。买之前核对：数量是「1/N」（N ≥ 1）、选中的是要用的选项、价格（叶子 2 → 1、天空石 80 → 1）、持有量、天空石保底；买后顶栏核心正好 +1、天空石减少 0 / 80，否则立即停止。购买框自动关闭时点取消。
- 异界准备界面不点原来切换钮的位置（那里是「战斗开始」按钮的右端）：异界读出来就是「战斗开始」模式，不会去切。
- 食人魔选了非异界难度：不导航，直接停止并提示（GUI 已锁定，这是引擎兜底）。

## 已知问题 / 后续
- **补核心没有实跑**：持有 27 个，要用完才会触发；只离线测试，加上采集时手动打开过购买框（点取消）。买完后游戏会不会弹出「获得道具」之类的框没见过：核对只看顶栏核心 +1 和天空石读数，中间有认不出的框会按通用弹窗规则处理，读数不对就停止。
- 购买框的数量「1/3」里 3 的含义（每日 / 每周限购，还是按持有算）不确定。模块只要求「1/N」且 N ≥ 1，不改数量。
- 核心不够时点「战斗开始」会怎样没见过（模块不会这么做）；万一弹出购买框，会点取消并停止。
- 托管只在食人魔实测：阿吉玛纳克、卡戴斯的异界在这个账号上都是「无记录」，开不了托管（模块会跳过并提示先手动通关一次）。手动打这两个的异界没有实跑。
- 异界托管进度框没有 PNG fixture：录屏是 JPEG，按钮模板的颜色校验通不过。真机上结算流程已经走通，离线测试复用普通难度的进度框截图。
- 顶栏光谱核心图标有光效动画，B06 那天和今天的截图差别很大；只能用图标中心的小模板，1280×720 下只有 0.82 分，所以阈值降到 0.75（其他界面最高 0.38）。
- 卡戴斯的准备界面整体比另外两个偏右下约 10 像素（静止后也一样），原因不明；模板照样命中、读数正确。
