## 真机看到的规则（2026-10-20，MuMu 1600×900）
- 大厅「商店」进去默认是「更新精选」（入场动画约 2–3 秒，期间点击被吞）。左侧菜单「商店」默认停在「一般」页签；「交易所」默认停在「竞技场」页签。选中的页签下面有一条亮蓝色光带。
- 商品列表两行，横向滑动。卡片间距 252，一屏完整显示 4 列（第 5 列被截掉一半）。「一般」10 件（多滑一点就能看全），「传承石」19 件（约 3 屏）。
- **列表有惯性**：0.6 秒拖 740 像素会甩出去 5 列以上（中间的商品直接跳过）；1 秒拖 500 像素挪约 650 像素。代码用 1 秒拖 400 像素（≈ 2 列）。
- 卡片：顶部商品名、右上「剩余/上限」（白底黑字；买完是灰的「0/3」）、按钮上方「每日购买 / 每周购买 / 账号限定」、按钮（能买是绿色，带价格图标和数字；买完是蓝灰色「完成购买」「N天后可购买」「12小时后可购买」）。不限购的没有「n/m」。
- **购买商品框有三种**：
  - 剩余 > 1：有数量条（最少 / -1 / +1 / 最多），默认选 1；「最多」= 剩余和买得起的较小值（行动力 210 时光谱核心最多 1/1）；按钮上是总价；
  - 剩余 = 1：没有数量条；
  - 越买越贵（亲密度献礼选择箱）：说明「此商品会根据购买次数发生价格的变动」，右边多一个「价格信息」。
  - 标题「购买商品」在有数量条的框里字小、位置高（两个模板）。秘密商店的购买框也是同一种框（金币价格）。
- 买完：**列表重新排序：买完的移到最后**，其他卡片往前挪。
  - 普琳每日免费商品：弹出「获得奖励」框（「成功购买商品，已获得以下道具。」+「点击关闭」，前 1 秒有光效），点关闭回到列表；
  - **行动力这类「入场券」没有获得奖励框**（实跑才发现）：购买框直接消失，顶部中间飘一条「入场券 40点行动力」提示约 1.5 秒（挡住顶栏的数字）。其他商品实跑时也都没有弹框。
- 每周重置：周二下午显示「5天后可购买」→ 周一的每日重置（北京时间周一 3 点）。每日的显示「12小时后可购买」（北京时间 3 点）。
- 顶栏随页签变：一般 = 友情点数 / 行动力 / 生命之叶 / 金币 / 天空石；传承石 = 传承石 / 银光传承石 / 金币 / 天空石；交易所 › 竞技场 = 竞技场点数 / 金币 / 天空石。

### 核对规则
- 只买 `CATALOG` 里选中的；**价格图标必须是规定的货币**（免费 / 友情点数 / 行动力 / 银光传承石 / 竞技场点数），认不出的（天空石、生命之叶、传承石）不买。同名的「光谱核心」靠「剩余/上限」和价格图标区分。
- 卡片：上限和 CATALOG 一致；固定价格的单价一致；顶栏够付。不符就跳过（记日志，不点）。
- 购买框：商品名、价格图标、剩余次数和卡片一致；有数量条的点「最多」后数量 = 最多、不超过要买的；总价 = 单价 × 数量；够付。不符点取消、跳过。
- 买完：等购买框消失、回到列表再停 2 秒（顶部提示飘完；中途出现「获得奖励」就点击关闭）后读顶栏：**天空石不变**；付款货币正好减少总价（行动力允许少减 3 点，买的时候会自然恢复）；免费商品没有货币可核对，要看到「获得奖励」才算。天空石变了 / 扣的数不对 → 整个任务立即停止（失败）。
- 点了购买 4 秒购买框还在 / 读数没变 → 算这次失败（不计数），购买框按规则点取消；同一件失败 2 次不再试。
- 亲密度献礼选择箱：已买次数 = 上限 − 剩余，到 5 次就记账不买。
- 账本：每日商品买完 / 显示买完记 `done`，每周的记 `week_done`；全记上的页不进去，全记上了就不进商店。光谱核心行动力不够没买满时不记，下次再看。

## 已知问题
1. 「下级神器强化石（一般）」开工时已买完，**价格和货币没见过**，按友情点数处理、不核对总价（只要求价格图标是友情点数、够付）。下周可以买时第一次实跑要看一眼日志。
2. ~~绿色货币的游戏内名字没核对~~ 用户告知叫**银光传承石**，已改（代码里的枚举值仍是 `crystal`）。
3. 「商店」默认开（用户要的功能）。已经保存过日常收取设置的玩家升级后，下次收菜也会开始买（正式版没有演练开关）。
4. 一页列表被商店更新、活动改动（商品增减、价格变化）时：单价不符的不买、找不到的在日志里提示「没找到」，不会买错，但要手动改 `CATALOG`。
5. 越买越贵的商品不核对价格上限，只限制每周次数（按卡片上的剩余/上限）。
6. 模拟器里卡片文字是模型给的（截图上的字买完不会变），卡片识别本身由 fixture 测试覆盖。
7. 前两次实跑的统计因任务失败没有计入买到的商品（history 里 `shop_buys` 为空），游戏里实际买成了：竞技场 40点行动力 × 3、一般 40点行动力 × 1。
8. 一页扫完约 10–30 秒（每屏 OCR 约 1.5 秒 + 滑动停稳），全部 14 件都要买时整项约 2 分钟。
